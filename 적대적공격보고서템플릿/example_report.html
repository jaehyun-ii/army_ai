2. 사용된 공격 기법

2.1 공격 방법

공격 유형: PGD (Projected Gradient Descent)

PGD는 다중 스텝 반복 최적화를 통해 적대적 perturbation을 생성하는 강력한 공격 기법입니다. FGSM보다 정교하며, 각 스텝마다 epsilon 제약 내에서 gradient 방향으로 이미지를 수정합니다. 객체 탐지 모델의 loss를 최대화하여 탐지 성능을 저하시킵니다.

2.2 공격 파라미터

파라미터 값 설명
Epsilon (ε) 8.0 최대 perturbation 크기 (픽셀당)
Iterations 300 최적화 반복 횟수
Alpha (α) 2.0 (ε/4) 스텝 크기 (PGD)
Intensity Level Medium 공격 강도 (균형)

2.3 실험 환경

배치 크기 32

5. 결론

5.1 실험 결과 요약

  • 공격 방법: PGD (Projected Gradient Descent)
  • 공격 강도: Medium (ε=8.0, iterations=300)
  • 테스트 이미지 수: 348 images (person class)
  • 공격 성공률: 73.2%
  • mAP 감소율: -68.5%

5.2 주요 발견사항

1. 높은 공격 성공률: PGD 공격은 73.2%의 높은 성공률을 보였으며, 대다수의 테스트 이미지에서 객체 탐지 성능을 크게 저하시켰습니다.

2. mAP 대폭 감소: mAP@0.5가 0.6843에서 0.2156으로 68.5% 감소하였으며, 이는 모델의 탐지 능력이 치명적으로 손상되었음을 의미합니다.

3. 탐지 신뢰도 저하: 공격 후 평균 confidence score가 58.3% 감소하여, 탐지된 객체조차도 낮은 신뢰도를 보였습니다.

4. False Negative 증가: False Negative Rate가 62.6% 증가하여 실제 존재하는 객체를 탐지하지 못하는 경우가 대폭 증가했습니다.

5. 육안 식별 어려움: ε=8.0의 perturbation은 육안으로 거의 식별이 불가능하여 실제 운용 환경에서 탐지가 어려울 것으로 예상됩니다.

5.3 권장사항

1. Adversarial Training 도입: PGD와 같은 강력한 공격 샘플을 학습 데이터에 포함시켜 모델의 강건성을 향상시켜야 합니다.

2. Input Preprocessing 강화: JPEG 압축, 가우시안 블러, 비트 깊이 감소 등의 전처리를 통해 perturbation을 완화할 수 있습니다.

3. 앙상블 모델 구축: 서로 다른 아키텍처의 모델을 앙상블하여 단일 모델 공격의 효과를 감소시킬 수 있습니다.

4. 이상 탐지 시스템 구축: 적대적 샘플을 탐지하는 별도의 이상 탐지 시스템을 도입하여 공격을 사전에 차단해야 합니다.

5. 정기적인 취약성 평가: 새로운 공격 기법에 대한 정기적인 평가와 대응 방안 수립이 필요합니다.
